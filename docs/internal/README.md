# Internal notes and archive

This directory keeps planning boards, architecture audits, glossary inventories, QA crosswalks, and exploratory infrastructure notes out of the default NVA pilot path.

The first-pass NVA-facing story is intentionally smaller:

- Data Quality Hygiene
- Manager Daily Brief
- safety boundaries
- access needed for a real pilot

The archived material is retained for implementation continuity, not as the recommended first read for NVA stakeholders.
